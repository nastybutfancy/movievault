# MovieVault 3.1 — Collector Home

Pierwszy etap przebudowy w kierunku aplikacji dla kolekcjonera fizycznych wydań.

## Co zmieniono
- nowy ekran Home oparty na zaakceptowanej makiecie
- stałe, markowe tło MovieVault zamiast wielkiego backdroppu filmu
- trzy główne akcje: dodawanie, skanowanie i losowanie filmu
- sekcja „Ostatnio dodane”
- cyfrowe półki według formatów
- odkrywanie kolekcji według kategorii
- statystyki kolekcjonera
- zachowane istniejące funkcje Google Sheets, TMDb, kolekcji i skanera
- mobilna dolna nawigacja
- nowa wersja cache Service Workera

## Wdrożenie
Wgraj zawartość folderu do głównego katalogu repozytorium GitHub Pages i zatwierdź zmiany.
Po publikacji wykonaj twarde odświeżenie strony lub usuń dane witryny, jeśli przeglądarka nadal pokazuje starą wersję.

## Ważne
Ta wersja nie zmienia backendu Google Apps Script. Korzysta z dotychczasowego API.
